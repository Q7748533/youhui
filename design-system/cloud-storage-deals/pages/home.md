# 首页页面覆盖规则

## 目标
让用户在首屏理解“官方价格比对”，并完成进入方案列表或对比页。

## 页面结构
1. 顶部导航：Deals / Providers / Compare / How it works
2. Hero：价值主张 + 两个 CTA + 数据可信度卡片
3. 快速筛选：Use case / Storage size / Sort by
4. 精选方案卡片：价格、币种、状态、验证时间、官方来源
5. 供应商入口：显示 12 家供应商及状态
6. 数据方法：官方来源、每 6 小时更新、不估价规则

## 首页专属规则
- 不在首屏放长表格；
- 主 CTA 使用品牌紫，不使用绿色；
- 价格卡片必须同时显示 Verified 或 No verified price；
- 最新更新时间靠近数据摘要；
- 手机端方案卡片单列排列；
- 保留首页现有 `/` URL 和 ItemList JSON-LD。
